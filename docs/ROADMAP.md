## 1. コンセプト

> **走る前から、旅ランは始まっている。**
> 知らない道を見つけて、下見して、自分だけのランニングコースを作るサービス。

- 旅先や出張先で走る人、休日にいつもと違う場所を走りたい人が対象
- 汎用の GPS 記録アプリやルート作成アプリと機能で張り合わない。**入口は「発見」で、そこから「計画」につなげる**

## 2. 体験の3本柱

| 柱 | 何ができるか | 主な画面 |
| --- | --- | --- |
| ① 発見 | 地元ランナーのおすすめコースを、写真・地図・距離・おすすめポイントから選べる | ダッシュボード（一覧と絞り込み） |
| ② 下見 | 走る前に、コースを地図と Street View でたどって確認できる | ルート詳細 |
| ③ 作成 | Street View で道を見ながら経由地を足したり動かしたりして、自分のコースを作れる | ルートエディタ |

- ③の **Street View と地図が連動するエディタ**を、他のサービスにない強みとして育てる
- 作成モードと下見モードは、地図・パノラマ・現在地点・経路の連動部分を共通にする

## 3. 無料と有料の線引き（案・確定ではない）

- **無料のままにするもの**：探す・見る・基本的なルート作成・投稿・共有
  - 投稿がたまることがサービス全体の価値になるので、作成と投稿には課金しない
- **有料の目玉候補**：Street View と連動したルート編集、高度な調整、複数案の比較
  - 課金するのは「Street View を見られること」ではなく「**連動して作れる編集体験**」
- プランと価格（どちらも仮）：7日間パス 190円（買い切り、自動更新なし）、Plus 月390円
- 下見モードを無料にするか有料にするかは未定。GPX 出力は、データの権利を確認してから決める
- ⚠️ **Google Maps Platform の規約を確認するまで、有料機能として約束しない。** 確認が取れなかった場合は、Street View は無料側に残して、独自の高度な機能を有料にする

### フェーズ1：「発見」の MVP
今のアプリは「作成」寄りで、入口になる「発見」がまだ無い。ここを作る。
- 大阪の厳選コース 10〜20本（大阪城・中之島など、実際に走って説明できるもの）を運営側で登録する
- おすすめ一覧のカードと、エリア・距離・テーマでの絞り込み
- ルート詳細で、地図上の経路・距離・目安時間・写真・おすすめポイント・スタート地点を見せる
- スマホで見やすくする
- 一般ユーザーの投稿は必須にしない。空っぽの SNS にならないよう、厳選コースから始める
- ランナー 2〜5人に使ってもらい、「走りたくなるか」「何を見て選ぶか」「足りない情報は何か」を聞く

### フェーズ2：「下見」と「作成」を強くする（Street View 連動）
- Street View と地図が連動するルートエディタの操作の流れとワイヤーを作る
- ルート詳細から Street View で下見できるようにする
- Maps・Routes・Street View の呼び出し回数と予算の管理を設計する

### フェーズ3：収益化の検証
- 課金を入れる前に、Google に規約を確認する（画面・操作・課金方法を1ページにまとめて問い合わせる）
- API 費用・決済手数料・税金・サポートの手間を試算する
- 7日間パスと月額 Plus のどちらが求められているかを、実際の購入テストで確かめる
- 有料フラグ、UI の出し分け、tRPC での権限チェックを入れるのは、規約の確認が取れてから

### いつか
- 一般ユーザーによる投稿・レビュー・おすすめポイント
- お気に入り、行きたいリスト、走った記録
- GPX 出力、デバイス連携、ナビ
- 地域スポンサー、アフィリエイト、自治体やイベントとの連携

## 5. 検証したい問い

1. 旅先や休日のランナーは、汎用のルート検索より地元の人のおすすめに価値を感じるか
2. 一覧に写真・距離・テーマ・おすすめ理由があれば、走りたいコースを見つけやすいか
3. 地図だけで作るのと比べて、Street View と連動した編集に価値を感じるか
4. Street View でコースをたどれると、実際に走りに行く決め手になるか
5. 無料でも投稿は十分に増えるか
