## タスクの理解

- 解決する問題、完了条件、対象外

## 作業モード

- 既定: ローカルエージェントは **確認モード**、Cloud Agent は **PRモード**（`AGENTS.md` の「作業モード」）
- 依頼に「commitして」「PRにして」「PRモード」がある場合、または Cloud Agent 起動指示で PR まで求められている場合は **PRモード**
- 確認モード中にユーザーが PR 操作を指示したら PRモードに切り替える

## 現状の関連実装

- 責務とデータフロー
- 関連ファイル、設定、テスト、既存パターン

## 実装方針と代替案

- 採用する手順、責務の配置、既存設計との整合理由
- 検討した選択肢、トレードオフ、不採用理由

- 共通化する案 / 共通化しない案

## 変更範囲

- 変更・新規・削除予定ファイルと理由
- UI、API、状態、DB、認証、外部サービス、互換性への影響

## リスクと検証

- 技術、セキュリティ、性能、アクセシビリティ、レスポンシブ、migrationのリスクと対策
- 追加・更新テスト
- 実行する検証: `npm run format:check && npm run check && npm run test:run && npm run build`（UI/Story 変更時は `test:storybook` も）
- 手動確認、実行不能な検証

## Gitと前提

- ベースbranch、作業branch候補、commit方針
- `main` / `staging` への直接 push・merge は行わない。**PRモード**のときだけ作業branch の push と main 向け PR を行う（`AGENTS.md`）
- コードから推測した前提とユーザー判断が必要な事項
